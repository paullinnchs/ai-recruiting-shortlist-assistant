AI Recruiting Shortlist Assistant

A simple command-line tool that compares resumes against a job description, ranks candidates, and generates recruiter-ready shortlist materials.

Built as a recruiter-assist workflow. Final screening and hiring decisions should remain with qualified human reviewers.

Key Features

The MVP keeps the workflow focused: parse resumes, score candidates, and produce outputs that recruiters can review quickly.

Resume Parsing

Reads `.txt`, `.pdf`, and `.docx` resumes from a local input folder.

Structured Scoring

Scores candidates using a 100-point rubric across skills, experience, tools, seniority, and fit.

Recruiter Outputs

Generates a ranked CSV, candidate report, recruiter notes, and outreach message drafts.

Sample Workflow

The project is designed for a short local demo or a lightweight recruiter workflow.

Add the job description

Paste the role requirements into `input/job_description.txt`.

Add candidate resumes

Place supported resume files in `input/resumes/`.

Run the assistant

Use `uv run python src/main.py` to parse, score, and rank candidates.

Review generated outputs

Open the CSV shortlist, candidate report, and outreach drafts in `output/`.

Run Locally Instructions

Install dependencies, start the Flask demo, then open the local web interface.

uv venv
uv pip install -r requirements.txt
uv run python src/web_app.py
Open http://127.0.0.1:5000
